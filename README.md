# Exploratory Testing Session – Used Car Marketplace

## 🔎 Context

This exploratory testing session was conducted as part of a QA training exercise focused on experience-based testing techniques.

The goal was to design and execute exploratory test charters on a live web application and document findings, test execution, and defect reports using a structured QA approach.

The exercise emphasized:

- Test charter design
- Time-boxed exploratory execution
- Defect identification in a production-like environment

## Overview

This project documents an exploratory testing session conducted on a public web application (used car marketplace). The goal was to evaluate search, filtering, sorting, and usability behavior using structured exploratory testing techniques.

## Scope

- Search functionality
- Filtering logic (brand, fuel type, price, etc.)
- Sorting behavior
- Edge cases and inconsistent system behavior
- UI consistency and usability

## Testing Approach

- Time-boxed exploratory testing
- Test charters (TC-1, TC-2, TC-3)
- Risk-based exploration
- Combination of functional and usability testing

## Techniques Used

- Exploratory Testing
- Equivalence Partitioning
- Boundary Value Analysis
- Negative / edge case testing

## Summary of Findings

5 issues were identified during the session, including:

- Data inconsistencies in search results
- Incorrect filter combinations
- Ambiguous sorting logic
- UI logic inconsistencies in featured listings
- Invalid range handling in filters

## Tools

- Manual testing
- Browser-based testing
- Jira-style bug reporting (documented in Markdown)
