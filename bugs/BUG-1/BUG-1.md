# BUG-1 – Inconsistent result count between brand filter and search button

## Severity: Medium (3)

## Description

The number of results displayed in the brand filter differs from the search result count.

Example:

- Brand filter: KIA (3507)
- Search results: 3446

## Steps to reproduce

1. Open search page
2. Select brand "KIA"
3. Compare filter count with search result count

## Expected result

Consistent result count across UI elements

## Actual result

Different counts are displayed
